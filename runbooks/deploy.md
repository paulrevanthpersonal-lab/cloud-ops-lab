# Deployment Rollback

1. Freeze additional changes and identify the release window.
2. Record version, commit, pipeline, configuration, and health-gate evidence.
3. Determine whether rollback is safer than forward remediation.
4. Restore the last known-good artifact and configuration.
5. Validate service health, dependencies, logs, and a representative user journey.
6. Communicate recovery and open a follow-up problem record.
